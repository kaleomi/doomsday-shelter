# 末日安全屋

> 重生回极寒末日降临前的第 14 天。筹钱、选安全屋、囤物资——然后活过 100 天，再迎来春天。

竖屏网页生存经营游戏，手机和电脑都能玩。纯静态 HTML/CSS/JS，没有任何构建步骤，双击 `index.html` 就能玩。

## 玩法

- **重生备战（第 1–14 天）**：贷款、卖房筹钱；在烂尾楼、小区民房、独栋别墅、地下堡垒里选一处安全屋；买家具、做改造、囤食物药品燃料。右上角的“备战清单”会提醒你还缺什么。很多“省事”的选择会埋下隐患，几天后找上门来。
- **末日降临（第 15 天起）**：钞票作废，晶核成为硬通货。室外会冷到零下一百多度，之后还有“蓝辉”辐射。
- **经营安全屋**：点击家具指派队员睡觉、锻炼、阅读、种菜、制造（左侧“⚡安排”一键安排）；用灶台做饭、烧雪水；壁炉每天烧木柴；修缮完整度，升级保温/防辐射/防御/仓储。
- **自由布置**：安全屋 → 家具 → 自由布置，移动、旋转家具。摆得巧有布局加成（暖炉旁、温室角、学习角、小厨房、影音区、恢复区、门岗）。
- **队员与羁绊**：剧情人物与随机幸存者，各有职业、品质、技能和装备。队员之间有羁绊：一起干活、并肩作战会越来越默契，挚友同队加攻，生死之交会替对方挡下致命一击。招募时栏位满了可以换人。
- **末日伙伴**：末日后可能遇到流浪狗。收养后它会参与战斗、跟着探索多嗅出物资、夜里示警，记得喂狗粮或变异肉。
- **探索城市**：13 个地点、39 条线路，在带迷雾的格子地图里捡物资、躲开或击败敌人。摸清外围的地点可以**派队员远征**几天，自动带回物资并写下远征日志。
- **战斗**：回合制自动战斗，可以集火、用药、撤退。**夜袭守卫战**：给队员分配正门/窗口/屋顶站位，布下尖刺陷阱、燃烧瓶、绊线雷，分 2–3 波打退来犯者。
- **军械改装**：工作台里给装备强化（+1 到 +10）、加装词条（锋利、吸血、铅衬、轻盈……），同型号装备共享改装。
- **天灾**：雪崩、冰雹、太阳风暴、超级寒潮、辐射尘暴、冰雾、极光夜、洪水、孢子雨。提前两天预警，可以在【安全屋】里花材料防备。
- **电脑桌小游戏**：2048 和贪吃蛇，玩一局主角心情变好。
- **结局与重生**：16 种结局。每个结局都给“重生点”，下一世可以激活“重生系统”（前世记忆、启动资金、战斗压制、神农、无限空间……）。
- **春天篇（第 101–160 天）**：活过 100 天并达成好结局后可以继续。冰雪消融、绿潮疯长，重建会、掠夺车队、绿潮会三方角力，新人物林檎和铁头，3 个新地点，新结局【春回大地】【新城奠基】。
- **难度**：休闲 / 标准 / 硬核（硬核结局重生点 ×1.6）。
- **每日挑战**：所有人同一天用同一个角色、同样的天气和天灾、同样的两条词条，30 天内拼分数，上全球排行榜（北京时间 0 点换题）。
- **成就与图鉴**：33 个成就，敌人 / 物品 / 人物图鉴。
- **存档**：3 个存档位；可以导出“存档码”或存档文件，换手机、换浏览器继续玩。

电脑上：空格 行动 · 数字键 选择选项 · 方向键/WASD 探索移动 · P 人员 · B 仓库 · S 商店 · E 探索 · H 安全屋 · L 日志。

## 运行

- **本地**：直接双击 `index.html`（所有脚本都是普通 `<script>`，标题字体也内嵌在 CSS 里，不需要本地服务器）。本地打开时没有排行榜，每日挑战成绩只存在本机。
- **存档**：自动保存在浏览器 localStorage。
- **手机**：可以“添加到主屏幕”，像 App 一样全屏打开（自带 manifest 与离线缓存）。

## 部署到 Cloudflare Pages

1. Cloudflare 控制台 → Workers & Pages → 创建 → Pages → 连接到 Git，选择本仓库。
2. 框架预设：`None`；构建命令：留空；构建输出目录：`/`。
3. 保存并部署。之后每次推送到主分支都会自动更新。

`_headers` 文件已经设置好 JS/CSS 的缓存策略，更新后玩家刷新就能拿到新版本。

### 开通每日挑战全球排行榜（可选，免费）

排行榜用的是 Cloudflare Pages Functions（`functions/api/scores.js`，会随部署自动生效）+ 一个 KV 存储。不开的话游戏照常能玩，挑战成绩只存在本机。

1. Cloudflare 控制台 → **Storage & Databases → KV** → **Create a namespace**，名字随便填，比如 `doomsday-shelter-scores`
2. 打开这个 Pages 项目 → **Settings → Bindings**（旧界面在 Settings → Functions → KV namespace bindings）→ **Add → KV namespace**
   - Variable name 填 **`SCORES`**（必须一模一样）
   - KV namespace 选刚才建的那个
3. 回到 **Deployments**，对最新一次部署点 **Retry deployment**（绑定要重新部署才生效）

验证：打开 `https://你的域名/api/scores?board=today`，看到 `{"board":"d2026…","list":[]…}` 就是通了；看到 `no-kv` 说明绑定没生效。

免费版 KV 每天 1000 次写入，每次上传成绩最多写 2 次，小规模够用。成绩只做了基本校验，挡不住专门作弊的人。

## 目录

```
index.html              入口
css/style.css           样式
css/font.css            标题字体（子集，内嵌 data URI，由 tools/build_font.py 生成）
js/data/                物品、安全屋、家具、职业技能、敌人、地点、结局、人物
js/data/extra.js        难度、天灾、装备词条、成就、伙伴、春天篇数据、陷阱
js/data/content/        事件内容（备战、主线、春天篇、安全屋专属、随机、气泡、探索、羁绊、伙伴、天灾、远征日志）
js/engine/              引擎：状态与存档、模拟、事件 DSL、战斗、探索
js/engine/ext.js        扩展系统：难度、天灾、伙伴、羁绊、远征、军械、成就、每日挑战、春天篇、布局加成
js/ui/                  界面：程序化美术、音效、面板、战斗、守卫战、探索、小游戏、标题
functions/api/scores.js 每日挑战排行榜（Cloudflare Pages Function + KV）
docs/CONTENT_SPEC.md    事件编写规范（条件/效果 DSL）
tools/validate.js       内容校验：node tools/validate.js
tools/autoplay.js       自动试玩（平衡测试用，不随游戏加载）
tools/build_font.py     重新生成标题字体子集
```

美术全部是代码绘制的 SVG/CSS，音效由 WebAudio 实时合成，仓库里没有任何图片或音频素材（图标除外）。标题字体是 Noto Serif CJK SC Black 的子集（SIL Open Font License 1.1）。

## 新增事件

事件是纯数据，写在 `js/data/content/*.js` 里，格式见 `docs/CONTENT_SPEC.md`。改完运行：

```bash
node tools/validate.js
```

如果新事件里出现了新的结局名或战斗名，再运行 `python3 tools/build_font.py` 更新标题字体子集（需要 fonttools 和 Noto Serif CJK 字体）。
