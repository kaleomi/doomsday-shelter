# 末日安全屋

> 重生回极寒末日降临前的第 14 天。筹钱、选安全屋、囤物资——然后活过 100 天。

竖屏网页生存经营游戏，手机和电脑都能玩。纯静态 HTML/CSS/JS，没有任何构建步骤，也不依赖服务器。

## 玩法

- **重生备战（第 1–14 天）**：贷款、卖房筹钱；在烂尾楼、小区民房、独栋别墅、地下堡垒里选一处安全屋；买家具、做改造、囤食物药品燃料。很多“省事”的选择会埋下隐患，几天后找上门来。
- **末日降临（第 15 天起）**：钞票作废，晶核成为硬通货。室外会冷到零下一百多度，之后还有“蓝辉”辐射。
- **经营安全屋**：点击家具指派队员睡觉、锻炼、阅读、种菜、制造；用灶台做饭、烧雪水；壁炉每天烧木柴；修缮完整度，升级保温/防辐射/防御/仓储。
- **招募队员**：剧情人物与随机幸存者，各有职业、品质、探索技能和生存技能，可以装备武器、防具、鞋子。
- **探索城市**：10 个地点、30 条线路。在带迷雾的格子地图里捡物资、躲开或击败敌人，走到 ❗ 推进剧情。
- **回合制战斗**：自动战斗，可以集火、用药、撤退。
- **14 种结局**：活过 100 天会根据安全屋与你的选择进入不同结局；每个结局都给“重生点”，下一世可以激活“重生系统”（前世记忆、启动资金、战斗压制、神农、无限空间……）。

电脑上：空格 行动 · 数字键 选择选项 · 方向键/WASD 探索移动 · P 人员 · B 仓库 · S 商店 · E 探索 · H 安全屋 · L 日志。

## 运行

- **本地**：直接双击 `index.html` 即可（所有脚本都是普通 `<script>`，不需要本地服务器）。
- **存档**：自动保存在浏览器 localStorage。
- **手机**：可以“添加到主屏幕”，像 App 一样全屏打开（自带 manifest 与离线缓存）。

## 部署到 Cloudflare Pages

1. Cloudflare 控制台 → Workers & Pages → 创建 → Pages → 连接到 Git，选择本仓库。
2. 框架预设：`None`；构建命令：留空；构建输出目录：`/`。
3. 保存并部署。之后每次推送到主分支都会自动更新。

`_headers` 文件已经设置好 JS/CSS 的缓存策略，更新后玩家刷新就能拿到新版本。

## 目录

```
index.html              入口
css/style.css           样式
js/data/                物品、安全屋、家具、职业技能、敌人、地点、结局、人物
js/data/content/        事件内容（备战、主线、安全屋专属、随机、气泡、探索、幸存者简介）
js/engine/              引擎：状态与存档、模拟、事件 DSL、战斗、探索
js/ui/                  界面：程序化美术、音效、面板、战斗、探索、标题
docs/CONTENT_SPEC.md    事件编写规范（条件/效果 DSL）
tools/validate.js       内容校验：node tools/validate.js
tools/autoplay.js       自动试玩（平衡测试用，不随游戏加载）
```

美术全部是代码绘制的 SVG/CSS，音效由 WebAudio 实时合成，仓库里没有任何图片或音频素材（图标除外）。

## 新增事件

事件是纯数据，写在 `js/data/content/*.js` 里，格式见 `docs/CONTENT_SPEC.md`。改完运行：

```bash
node tools/validate.js
```
