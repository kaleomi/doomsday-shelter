# 《末日安全屋》内容编写规范

这是一款竖屏网页生存经营游戏（手机/电脑都能玩）。玩家**重生**回到极寒末日降临前 14 天，筹钱、选安全屋、囤物资；第 15 天末日降临后，管理安全屋与队员，探索城市、战斗、烹饪种植，目标是活过 100 天。

游戏的核心体验来自**事件**：玩家每按一次【行动】，时间推进一个时段（每天 6 个时段：6/9/12/15/18/21 点，夜里另有夜间事件），并可能弹出一个事件。事件有正文和 2–4 个选项，选项产生结果文字和效果。

你要写的就是这些事件。所有内容写成 JS 数据文件，放在 `js/data/content/`。

## 一、世界观（原创设定，务必遵守）

- 城市：**临川市**。时间：2049 年。游戏第 1 天 = 8 月 1 日，第 15 天（8 月 15 日）末日正式降临。
- 灾变：太阳超级耀斑 → 全球寒潮 + 电磁冲击。第 11 天起气温断崖式下跌（-25℃ → 第 30 天后常年 -90~-110℃）。第 16 天后，一种被称为**“蓝辉”**的不明辐射随着降雪弥漫，辐射逐日升高；长期暴露的人和动物会变异。
- **晶核**：变异生物体内长出的蓝绿色结晶，蕴含能量，末日后取代钞票成为通货。末日后**金钱作废**（只在末日前能用）。
- **情报**：探索地点需要消耗情报；来自广播、交谈、搜索等。
- 主角前世：在末日里撑了很久，最后死于好兄弟**周恪**的背刺。重生后带着前世记忆，知道很多事情会怎样发生（可以写“前世的记忆告诉你……”）。
- 怪物：变异犬、变异鼠群、冰原狼、霜甲熊、冻尸（冻僵后仍在游荡的感染者）、辐射变异体、雪怪、实验体。
- 人类威胁：混混、暴徒、持枪匪徒、**白霜教**（崇拜寒冷的邪教，信徒带着发蓝光的晶核匕首，宣称“霜神”降临是净化）。

### 安全屋类型（玩家第 2 天选择）

| 类型 | 特点 | 专属结局条件（第 100 天检查） |
|---|---|---|
| 烂尾楼 | 便宜、面积大、漏风、防御弱 | 三项改造≥3级 → 【钢铁丛林】 |

| 独栋别墅 | 舒适、能住很多人、惹眼招贼 | 成员≥5 → 【雪中暖巢】 |
| 地下堡垒 | 昂贵、几乎坚不可摧、压抑 | 直接 → 【地下安居】 |

另外：拿到标记 `军方联络` 并活过 100 天 → 【官方据点】（优先级最高）。

## 二、事件数据格式

```js
(function () {
  DS.addEvents('prep', [          // pool 名由你负责的文件决定（见第六节）
    {
      id: 'prep_loan',            // 全局唯一，前缀见第六节
      day: 1,                     // 触发日：数字=当天必定触发；[3,6]=在这个区间内某天触发
      cat: '剧情',                 // 剧情/交易/战斗/物资/社交/完整度/维护/人员/训练/家具/探索
      scene: 'phone',             // 插图场景（见下）
      who: '彪哥',                 // 可选：说话人（显示名字标签）
      cond: ['!flag:已借贷'],      // 可选：触发条件，全部满足才可能触发
      text: '启动资金是眼下最现实的问题……',
      opts: [
        {
          t: '走银行渠道',           // 选项文字，尽量 ≤ 12 字
          r: '银行审批比想象中顺利，你拿到了 50 万信用贷。',  // 结果文字
          fx: ['money:+500000', 'flag:已借贷'],             // 效果
        },
        {
          t: '找彪哥借七十万',
          req: ['stat:力量>=5'],    // 可选：前提条件（不满足时选项置灰并显示原因）
          cost: ['money:5000'],     // 可选：选择时立即支付（付不起则置灰）
          r: '彪哥把钱转了过来，借据上金额那一栏是空的。',
          fx: ['money:+700000', 'flag:已借贷', 'flag:隐患_空白借据', 'contact:彪哥', 'sched:5:prep_shark_visit'],
        },
        {
          t: '赌一把',
          rnd: [                    // 随机结果：w 是权重。第一个结果视为“好结果”，主角运气越高越容易出
            { w: 40, r: '手气不错，翻了一倍。', fx: ['money:+200000'] },
            { w: 60, r: '输得精光。', fx: ['money:-100000', 'mood:-5'] },
          ],
        },
        {
          t: '让他们吃点苦头',
          r: '你抄起棒球棍迎了上去。',
          battle: 'street',         // 战斗模板（见第五节），必须同时给 win / lose
          win: { r: '混混们捂着脸跑了。', fx: ['flag:末世前打架'] },
          lose: { r: '你被打得鼻青脸肿。', fx: ['hp:-30%', 'status:轻伤'] },
        },
      ],
    },
  ]);
})();
```

字段说明：

| 字段 | 必填 | 说明 |
|---|---|---|
| id | 是 | 唯一 ID |
| day | 剧情类建议填 | 数字或 `[min,max]`；随机事件一般填区间限制出现阶段 |
| cat | 建议 | 事件类别，影响标题和随机抽取 |
| scene | 建议 | `snow door phone fight trade storm room city night radio lab fire blood chat ruin car hospital market cold warm` |
| who | 否 | 说话人。`scene:'phone'` 或 `'chat'` 时会显示成手机聊天气泡 |
| cond | 否 | 条件数组 |
| w | 否 | 随机事件权重（默认 10） |
| cd | 否 | 随机事件冷却天数（默认 12；剧情事件只触发一次） |
| repeat | 否 | `true` 表示随机事件可重复（受 cd 限制）。随机池默认可重复 |
| slot | 否 | `'night'` = 只在夜间触发（夜袭等）；`'day'` = 只在白天 |
| text | 是 | 正文，40–160 字为宜，最多 260 |
| opts | 是 | 2–4 个选项（只有 1 个选项也可以，例如纯叙述） |

选项里：`r`+`fx` / `rnd` / `battle`+`win`+`lose` / `next`（立即接续另一个事件 ID）四选一（`next` 可以和 r/fx 同时出现：先显示结果再接续）。

### 文本占位符

- `{name}` 主角名字；`{他}` 主角的他/她
- `{member}` 本事件选中的一名队员（不是主角）；`{m他}` 该队员的他/她
- 使用 `{member}` 或任何 `m.` 效果时，`cond` 里必须有 `members>=2` 或 `job:某职业`（会优先选中该职业的队员）

## 三、条件 cond / req（字符串，全部满足才成立；值里的 `|` 表示“或”；前缀 `!` 表示取反）

| 写法 | 含义 |
|---|---|
| `flag:名字` / `!flag:名字` | 有/没有某标记 |
| `flag:名字>=2` | 计数标记比较 |
| `apoc` / `!apoc` | 末日是否已降临 |
| `house:小区民房\|独栋别墅` | 当前安全屋类型；`house:none` = 还没有安全屋 |
| `money>=100000` `crystal>=200` `intel>=3` | 资源比较（`>= <= > < =`） |
| `stat:力量>=7` | 主角属性（力量 灵巧 学识 运气 速度 防御） |
| `mood<30` `hp<50%` `energy<20` `hunger<20` `thirst<20` | 主角状态 |
| `members>=2` | 安全屋人数（含主角） |
| `member:苏晚` | 某剧情人物已在队伍中 |
| `job:医生` | 有某职业的队员（并选中他作为 `{member}`） |
| `item:木柴>=5` | 仓库物品数量 |
| `integrity<50` | 安全屋完整度（0–100） |
| `temp<0` `outtemp<-50` `rad>=40` | 室内温度 / 室外温度 / 室内辐射 |
| `day>=20` | 天数 |
| `furn:壁炉` | 拥有某家具 |
| `mod:防御>=2` | 改造等级 |
| `vehicle:轿车\|越野车` / `vehicle:none` | 载具 |
| `gender:女` | 主角性别 |
| `contact:周恪>=20` | 与联系人的好感 |
| `chance:0.3` | 30% 几率成立 |
| `loc:hospital` | 当前探索地点（仅探索事件） |
| `rebirth>=1` | 已经重生过至少 1 次（多周目内容） |

## 四、效果 fx（字符串数组，按顺序执行）

| 写法 | 含义 |
|---|---|
| `money:+500000` `money:-20000` | 金钱（仅末日前有意义） |
| `crystal:+120` `intel:+2` | 晶核 / 情报 |
| `item:矿泉水:+6` `item:压缩饼干:-2` | 物品增减（名称必须来自物品表） |
| `loot:食物:2` | 随机 2 种物资（每种 1–3 个）。类别：食物 食材 材料 医疗 武器1/2/3 防具1/2/3 鞋子1/2/3 |
| `stat:力量:+1` | 主角永久属性 |
| `hp:-10` `hp:-20%` `hp:+30%` | 主角生命（绝对值或最大生命百分比） |
| `energy:-5` `hunger:+10` `thirst:-5` `mood:-3` | 主角体力/饱腹/饮水/心情（0–100） |
| `team.mood:+3` `team.hp:-10%` `team.energy:-5` | 全员（含主角） |
| `m.mood:+5` `m.hp:-20%` `m.stat:力量:+1` `m.status:轻伤` `m.cure:感冒` | 本事件选中的队员 |
| `m.leave` / `m.die` | 该队员离队 / 死亡（慎用） |
| `status:感冒` / `status:rnd:轻伤` | 主角 / 随机一名成员获得伤病 |
| `cure:感冒` `team.cure:感冒` | 治愈 |
| `flag:名字` / `flag:名字:+1` / `unflag:名字` | 设置标记 / 计数 / 清除 |
| `house:def:+5` `house:integrity:-8` `house:insul:+0.03` `house:antirad:+0.03` `house:cap:+50` | 安全屋属性（完整度 0–100） |
| `house:get:小区民房` | 获得安全屋（仅选房事件用） |
| `recruit:苏晚` | 剧情人物加入（弹出加入提示） |
| `recruit:rnd` / `recruit:rnd:医生` | 弹出一名随机幸存者的招募卡，玩家决定收不收 |
| `contact:彪哥` / `aff:周恪:-20` | 添加联系人 / 改变好感 |
| `unlock:cook` | 解锁功能：cook farm craft recruit explore phone blackmarket shop market mods vehicle |
| `unlock:loc:market` | 解锁探索地点 |
| `shop:食品` | 结果关闭后打开商店：食品 药店 建材 户外 黑市 家具 车行 装修 集市 |
| `furn:豪华床` / `vehicle:摩托车` | 直接获得家具 / 载具 |
| `sched:3:事件ID` | 3 天后触发某事件（**隐患回收的核心手段**） |
| `goto:事件ID` | 立即接续某事件 |
| `ending:锒铛入狱` | 立即进入结局（慎用） |
| `log:文字` | 只写一条日志 |

### 隐患机制（重要的趣味来源）

末日前的很多“省事”选项会埋下隐患：设置 `flag:隐患_XXX`，并用 `sched:N:事件ID` 或在后续事件 `cond` 里检查这个标记，几天后回收（火灾、讨债、被盯上、设备故障……）。玩家激活“前世记忆”天赋时，带隐患标记的选项会显示 ⚠ 提示，所以隐患标记**必须以 `隐患_` 开头**。

## 六、数值参考

- 末日前金钱：开局 0；第 1 天通过贷款/卖房可得 50 万–300 万。安全屋 40 万–400 万。小事件 ±1000–5 万，大事件 ±10 万–100 万。
- 晶核（末日后）：小事件 ±20–150，中事件 ±150–500，大奖励 ±500–1500。
- 情报：±1–4，罕见 ±5–8。
- 心情：±1–8，重大打击 -10~-15。
- 体力/饱腹/饮水：±3–15。
- 生命：-5%~-30%，极少 -50%。
- 物品：1–6 个为主；食物水大礼包可以到 10–20。
- 战斗：末日前只用 `street` / `loan_shark`；第 15–30 天用 dog/dogs/rats/thugs/frozen；30–60 天用 wolves/gang/cultists/horde/mutant；60 天后可用 gunmen/mutants/bear/cult_boss/boss_mutant/yeti/lab_boss/raiders。敌人等级会随天数自动成长。
- 好的选项不应该总是“最优”：要有代价和取舍（花钱 vs 冒险 vs 心情 vs 埋隐患）。

## 七、文风

- 简体中文，短句，画面感强，冷峻里带一点黑色幽默。第二人称“你”。
- 正文交代情境和抉择，结果文字写“发生了什么”，不要写成说明书（不要写“你获得了 XX”，奖励会自动显示）。
- 选项文字是“动作”，简短有力：`锁死大门` `把库存截图发给她` `假装不在家`。
- 不要血腥猎奇、不要色情、不要涉及真实人物和真实品牌。
- 一律原创，不要照搬任何现有作品的句子。

## 八、扩展玩法（第二版新增）

### 8.1 新增条件

| 写法 | 含义 |
|---|---|
| `chapter>=2` | 已进入**春天篇**（第 101–160 天） |
| `pet` / `!pet` | 有 / 没有末日伙伴（狗） |
| `petloyal>=50` | 伙伴忠诚度（0–100） |
| `disaster:冰雹\|雪崩` | 今天正处在某种天灾中 |
| `forecast:冰雹` | 已收到某天灾预警（还没来） |
| `prep:冰雹` | 已经为这次天灾做好防备 |
| `bond>=50` / `bond<0` | `{member}` 与 `{member2}` 之间的羁绊（-100–100） |
| `diff:硬核` | 难度：休闲 / 标准 / 硬核 |
| `daily` / `!daily` | 是否每日挑战（一般不用） |

### 8.2 新增效果

| 写法 | 含义 |
|---|---|
| `pet:get` | 收养一只狗（名字随机）。事件 `cond` 必须有 `!pet` |
| `pet.leave` | 伙伴离开（慎用） |
| `pet.loyal:+10` `pet.hp:-30%` `pet.hunger:+20` | 伙伴忠诚 / 生命 / 饱腹 |
| `bond:+10` / `bond:-15` | 改变 `{member}` 与 `{member2}` 的羁绊 |
| `m2.mood:+5` `m2.hp:-20%` `m2.stat:力量:+1` `m2.status:轻伤` | 作用在第二名队员 `{member2}` 身上 |
| `prep:洪水` | 为某天灾做好防备（例如邻居帮你垒了沙袋） |

### 8.3 新增占位符

- `{member2}` / `{m2他}`：第二名队员（不是主角，也不是 `{member}`）。用到它们、`m2.*`、`bond` 时，`cond` 里必须有 `members>=3`。引擎会自动挑一对满足所有 `bond` 条件的队员。
- `{pet}`：伙伴的名字。用到 `{pet}` 或 `pet.*` 时，`cond` 里必须有 `pet`。

### 8.4 春天篇（第 101–160 天）

活过第 100 天并达成结局后，玩家可以选择“继续：春天篇”。

- **解冻**：气温从 -95℃ 一路回升，第 160 天前后回到 10℃ 左右；积雪融化带来洪水，蓝辉辐射逐渐下降。
- **绿潮**：被辐射催化的植物疯长——**藤蔓怪**（会缠住人）、**孢子体**（喷毒孢子）、**泥沼鳄**（解冻的江滩里爬出来的变异兽），植物园深处长着一株巨大的**母株**，它的孢子能让人变得温顺、失去意志。
- **三股势力**：
  - **临川重建会**：召集人 **沈砚秋**（前城市规划局工程师，冷静、务实），想在市中心广场建立“新城”，需要电力、粮食和安全三样东西。
  - **掠夺车队**：头目 **老鸦**（独眼，开改装油罐车，奉行“雪化了，规矩也化了”），向各个安全屋收“过路费”。技师 **铁头** 想脱离车队（可招募：`recruit:铁头`）。
  - **绿潮会**：白霜教的残余改信了植物，大祭司 **青姥**（原植物园的老研究员）宣称“母株是新的大地母亲”，用孢子控制信徒、绑架幸存者。
- **林檎**：植物学研究生，躲在植物园温室里，知道母株的弱点（可招募：`recruit:林檎`）。
- 春天篇敌人：藤蔓怪、孢子体、泥沼鳄、掠夺者、绿潮祭司（首领）、母株（首领）。
- 新探索地点：`riverbank` 解冻江滩（等级16）、`greenhouse` 植物园（等级18）、`downtown` 市中心（等级20）。需要用 `unlock:loc:` 解锁（江滩会在第 101 天自动解锁）。
- **结局**：第 160 天检查。设置了 `flag:新城奠基` → 【新城奠基】；否则 → 【春回大地】。
- 新战斗模板：`vines` 藤蔓怪、`spores` 孢子体群、`croc` 泥沼鳄、`looters` 掠夺车队、`green_cult` 绿潮会（首领）、`mother_plant` 母株（首领）。

### 8.5 天灾

第 20 天起会不定期发布天灾预警（提前 2 天），玩家可以在【安全屋】里花材料防备。天灾当天的效果由引擎自动结算，事件只负责“当天发生的小故事”，条件写 `disaster:XX`。

| 天灾 | 章节 | 天数 | 效果 |
|---|---|---|---|
| 雪崩 | 1 | 1 | 完整度大降 |

| 太阳风暴 | 1/2 | 3 | 收音机、电脑、监控失灵，制造变慢 |

### 8.7 远征日志模板

队员可以被派去远征（离家数天）。远征报告里的流水账来自 `DS.EXPEDITION_LOGS`（`js/data/content/expedition.js`）：

```js
DS.EXPEDITION_LOGS = {
  depart: ['{who}和{who2}背上行囊，往{loc}的方向去了。'],
  day: ['{who}在一辆侧翻的公交车里过了一夜。'],   // 第一章的路上见闻
  spring: ['泥水没过了脚踝，{who}一步一滑。'],      // 春天篇的路上见闻
  loot: ['{who}在{loc}的地下室里翻出了{item}。'],
  fight: ['{foe}从雪堆里扑了出来，{who}抄起家伙迎了上去。'],
  hurt: ['{who}的胳膊被划开一道口子，草草包扎了一下。'],
  good: ['{who}一行人满载而归，老远就冲你挥手。'],
  bad: ['{who}他们回来时两手空空，谁也不想说话。'],
};
```

占位符：`{who}` `{who2}`（队伍里的两个人，只有一人时相同）、`{loc}` 地点名、`{item}` 物品名、`{foe}` 敌人名。每条 15–45 字。
